# Changelog

## 1.1.0 — Working State

- Reworked the Flet interface with a collapsible navigation sidebar and view-scoped conversion log.
- Added the Markdown editor preview, draggable preview split, formatting toolbar, clear/close flow, and searchable built-in Help.
- Improved theme handling, profile persistence, typography controls, font selection, and code-font packaging.
- Added footnote handling and theme-aware code formatting in the Markdown preview.
- Preserved full conversion diagnostics and made the conversion log selectable as a single text block with a clipboard action.
- Fixed duplicate Pandoc LaTeX highlighting macro definitions that prevented code-block PDF exports.
- Added the Windows self-extracting installer workflow for per-user installation and setup of Pandoc and MiKTeX.
- Added this project's AI-oriented architecture and maintenance brief in `PROJECT_OVERVIEW.md`.

This release is published as a working state. The installer is not code-signed; Windows SmartScreen may show a warning.
